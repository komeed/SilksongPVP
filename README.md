# Silksong PVP Mod
Hello! This is a cool c# project I worked on a few months after Silksong released. After realizing that all of the popular silksong multiplayer/pvp mods were only supported on windows and not mac (my personal device), I created my own one!
I've recieved 1144 downloads since release! mod page: https://www.nexusmods.com/hollowknightsilksong/mods/927 

# What I learned
- relative to my c/c++ projects there was much less hardware involvement
- it was mostly a test of my general programming skills
